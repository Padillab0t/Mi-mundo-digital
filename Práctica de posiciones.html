Práctica de Posiciones en CSS

Navegación / Encabezado con position: sticky

1. Position: Static

Es la posición por defecto. Los elementos siguen el flujo normal del documento.

Estático (Static)

2. Position: Relative

Se desplaza respecto a su posición original usando top, left, etc.

Relativo (Relative)

3. Position: Absolute

Se posiciona con respecto a su contenedor padre más cercano que tenga posición no estática (position: relative).

Contenedor Padre (position: relative)
Absoluto (Absolute)

4. Espacio para Probar Scroll

Haz scroll hacia abajo para observar el comportamiento de sticky y fixed.

Fijo (Fixed)
